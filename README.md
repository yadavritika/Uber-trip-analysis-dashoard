#Uber Trip Analysis 🚖

Project Overview

This project focuses on analyzing 50,000+ Uber trip records to understand trip patterns, revenue, trip duration, distance, and popular pickup and drop-off locations. The goal was to clean the data, explore trends, and present useful insights through an interactive Power BI dashboard.

Tools Used

- Python: Data cleaning and exploratory data analysis
- SQL: Data querying and analysis
- Power BI: Interactive dashboard and visualizations
- Pandas, NumPy, Matplotlib: Data processing and visualization

Dashboard Features

- KPI cards for total trips, revenue, average distance, and duration
- Interactive filters for exploring trip data
- Day vs. night trip analysis
- Trip trends and revenue analysis
- Pickup and drop-off location analysis

Key Insights

- Identified the Upper East Side as an important pickup and drop-off area.
- Analyzed differences between daytime and nighttime trips.
- Explored trip distance, duration, and revenue patterns.
- Cleaned missing values, duplicates, and inconsistent data to improve data quality.

Skills Demonstrated

Data Cleaning | Exploratory Data Analysis | SQL | Python | Power BI | Data Visualization | Business Insights
